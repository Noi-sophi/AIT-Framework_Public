# 形式体系（基底）

## 0. 位置づけ（最小）
- meta は実在界（world）ではなく、各射影（physical/agent/social）を記述する **形式体系（射影先）**。
- 各射影は、形式体系に対してモデル（Domain/Interpretation）を供給する（= Adapter）。

## 1. 全体方針（最小）
- 形式体系は **字句基底 / 構文基底 / 意味基底** に分割する。
- 運用標準は **Closed + Binder-free**（自由変数なし、束縛子なし）。
- 真理値は **Heyting 代数 H** をパラメータとして凍結し、説明・試験用の既定例として **3値鎖 H3={0<u<1}** を併記する。
- 真理値出力は常に **TruthValue = (value∈H, source∈{world,theory})** のペアとする。
- 合成（∧,∨,→,¬）は **同一 source のみ許可**。source 混在は「照合」関数に回す。

---

# 2. 字句基底（Lexical Base）

## 2.1 定義（最小）
- 担体 U とゲート Gate を置く：
  - U：入力担体（文字列・トークン候補・記号候補など）
  - Gate: U → {in, out, ?}

## 2.2 生成物（最小）
- Tok := { u∈U | Gate(u)=in }
- Amb := { u∈U | Gate(u)=? }

## 2.3 規約（最小）
- 形式化済み（AST入力）を標準とする限り、Amb は原則として構文基底へ渡さない。
- Amb は「未確定な入力媒体側の問題」として保持し、意味基底の u（未決定）とは別物として扱う。

---

# 3. 構文基底（Syntactic Base）

## 3.1 シグネチャ（最小）
- Var：変数集合（単一ソート）
- Const：定数記号
- Func_n：n項関数記号
- Pred_n：n項述語記号
- Conn：結合子（⊤, ⊥, ¬, ∧, ∨, →）

> 将来予約：束縛子（∀, ∃, λ 等）

## 3.2 抽象構文（AST：最小）
- Term:
  - t ::= x | c | f(t1,...,tn)
- Formula（Binder-free）:
  - φ ::= P(t1,...,tn) | ⊤ | ⊥ | ¬φ | (φ∧ψ) | (φ∨ψ) | (φ→ψ)

## 3.3 自由変数と Closed
- FV(x) = {x}
- FV(c) = ∅
- FV(f(t1,...,tn)) = ⋃ FV(ti)
- FV(P(t1,...,tn)) = ⋃ FV(ti)
- 結合子は FV を和で伝播
- Closed(e) :⇔ FV(e)=∅

## 3.4 運用標準（凍結）
- Binder-free：束縛子が出現しない
- Closed：FV=∅
- よって、環境 ρ を空に縮退できる（意味基底参照）

---

# 4. 意味基底（Semantic Base）

## 4.1 真理値（Heyting 代数 H：パラメータ凍結）
- H=(H, ≤, ∧, ∨, 0, 1, →)
- ¬a := (a→0)

> 既定例（試験用）：H3={0<u<1}（鎖）。∧=min, ∨=max、→は随伴で決まる。

## 4.2 TruthValue（生成源タグ込み）
- TruthValue := (value, source)
  - value ∈ H
  - source ∈ {world, theory}

## 4.3 Domain と環境（最小）
- D：非空集合（値ドメイン）
- ρ: Var ⇀ D（部分写像）
- 運用標準：Closed のため ρ=∅ を既定

## 4.4 解釈（Adapter が供給）
- I(c) ∈ D
- I(f): D^n → D
- I(P): D^n → H

> 重要：原子真理値の生成（いつ 0/u/1 を返すか）は I(P) 側の責務であり、意味基底は結合子の合成のみを担当する。

## 4.5 評価（Binder-free）
- ⟦t⟧_{I,ρ} ∈ D
  - ⟦x⟧_{I,ρ}=ρ(x)（未定義なら評価不能：運用標準では Closed のため出現しない）
  - ⟦c⟧_{I,ρ}=I(c)
  - ⟦f(t1,...,tn)⟧_{I,ρ}=I(f)(⟦t1⟧,...,⟦tn⟧)

- ⟦φ⟧_{I,ρ} ∈ H
  - ⟦⊤⟧=1, ⟦⊥⟧=0
  - ⟦φ∧ψ⟧=⟦φ⟧∧⟦ψ⟧
  - ⟦φ∨ψ⟧=⟦φ⟧∨⟦ψ⟧
  - ⟦φ→ψ⟧=⟦φ⟧→⟦ψ⟧
  - ⟦¬φ⟧=⟦φ⟧→0
  - ⟦P(t1,...,tn)⟧ = I(P)(⟦t1⟧,...,⟦tn⟧)

# 5. Adapter（分業：world/theory）

## 5.1 WorldAdapter（world→theory 写像）
- 入力：各射影の State/Observe/Constraint/Update
- 出力：その時点の I_world（特に I_world(P):D^n→H）
- 評価結果は source=world を付与：
  - Eval_world(φ) := (⟦φ⟧_{I_world,∅}, world)

## 5.2 TheoryAdapter（数学＝形式体系対象）
- 入力：理論 T（公理＋推論規則）、（任意）探索状態
- 出力：I_theory（特に I_theory(P):D_T^n→H）
- 評価結果は source=theory を付与：
  - Eval_theory(φ) := (⟦φ⟧_{I_theory,∅}, theory)

> TheoryAdapter の「u」は、独立/未探索などの内訳を内部で持ってよいが、形式体系コアは (value∈H, source=theory) までを扱う。

---

# 6. source 規約（合成と照合）

## 6.1 合成（標準）
- 同一 source の TruthValue 同士のみ、結合子合成を許可する。
  - (v1,s) ⋄ (v2,s) := (v1 ⋄_H v2, s)   （⋄∈{∧,∨,→}）
  - ¬(v,s) := (¬_H v, s)

## 6.2 混在（例外：照合に回す）
- source が混在する場合は合成しない。
- 代わりに照合関数を用いる：
  - Compare( (v_w,world), (v_t,theory) ) → Diff
  - Diff は最小として「(v_w, v_t) を返す」でもよい。
  - 推奨：一致/差分/未決定優勢などの分類ラベルを付与（NOTE側で実装可）。

---

# 7. 既定試験（H3）
- H3={0<u<1} を既定例として、結合子合成の単体試験を行う。
- 例：原子値が u の場合、φ∨¬φ が 1 にならないことを確認する（排中律の非自明性の確認）。
