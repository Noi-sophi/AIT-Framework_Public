# AITF 基本版（Core + Standard）

## 0. この文書について

このREADMEは、AITFを初めて読む人のための入門・案内文書である。
CANONの定義・規約を変更・拡張するものではなく、理論内容については各CANONを正とする。

正式な現行基本版は、AITF vNextのCoreとStandardを中心とする。
まずこのREADMEで全体像を確認し、Core、Standardの順に読むことを想定している。
設計理由や検証例を確認する場合は、対応するSupportを参照できる。

## 1. AITFの目的

AITFは、有限agentが `world` を分析するための共通フレームワークである。
異なる成立条件・関係・構造を区別し、分析上の混同を防ぐことを目的とする。

同じ事柄でも、物理的な条件、agentに局所的な条件、複数agent間の関係、形式や記述に関わる構造では、検討すべき差異が異なりうる。
AITFは、こうした差異と、分析に用いる前提・依存関係を保持しながら検討するための共通基盤を与える。

有限agentによる利用は設計上の出発点であり、すべてのagentが有限であることをCoreが規定するものではない。
また、分析される対象そのものにagentが含まれる必要はない。

StandardはCoreの基礎概念を再定義せず、具体的な分析アルゴリズムや個別moduleの構造も定めない。

### 2.1 Coreで扱うもの

以下はCoreの概要であり、定義本体はCoreを参照する。

- `world`：AITFが扱う事柄が成立し、agentもそれに関与する現実。
- `agent`：`world` との関係において、`world` を扱いうる主体。
- 有限性：agentによる取り扱いと、その対象・条件との関係において現れる、区別・情報・資源・アクセスなどに関する制約。
- aspect：分析において区別して扱う条件・関係・構造の種類を指定するindex。

Coreは、次の四aspectを用いる。

| aspect | 関わる条件・関係・構造 |
| --- | --- |
| `physical` | 物理的な条件・相互作用・制約 |
| `agent` | agentに局所的な条件・相互作用・差異 |
| `social` | 複数agent間の関係、共有された条件、制度的・社会的構造 |
| `meta` | 形式・記述・推論その他の形式的構造 |

四aspectは対象を排他的に分類するためのものではなく、同じ事柄に複数適用できる。
Coreはaspect間の階層・包含・還元や一般的な優先順位を仮定しない。

### 2.2 Standardで扱うもの

Standardは、分析対象と問いまたは目的に照らし、分析結果に影響しうる範囲で次の規律を適用する。
以下は概要であり、具体的な適用範囲・条件はStandardを参照する。

- 分析上重要な差異の区別：結果に影響しうる差異を、根拠なく同一視しない。
- 成立範囲の差異の保持：内容や関係が成立する範囲に影響する差異を失わない。
- 前提・依存関係の明示：重要な条件・前提・接続を無言で省略せず、不明なものや分析者が補った仮定を区別する。
- 由来・分析上の扱いの区別：与えられた内容、導入した仮定、推論の結果、未確定の内容などを、必要な範囲で混同しない。

これらは、あらゆる差異の列挙や、関係しうる情報の網羅的な取得を要求するものではない。

## 3. Supportの位置づけ

Supportは、CANONの理解・検証・改訂に役立つ説明を保持する補助資料であり、CANONではない。
Supportの説明や例から新たなCANON上の規定が自動的に導かれることはなく、内容が衝突する場合はCANONを正とする。

Core Supportには、旧Coreや旧体系で採用していた区別・用語を撤去した理由も含まれる。
これらは設計上の経緯を説明するものであり、旧体系を現在の基本版の規定として参照するものではない。
将来の候補や未確定事項についても、現在採用済みの概念・moduleを示すものではない。

## 4. 基本版の完成範囲と限界

CoreとStandardによる基本版の設計は一区切りついた。
これは、共通基盤と分析の共通規律を定める範囲での区切りであり、AITF全体の理論的完全性を保証するものではない。

AITFの利用やStandardへの適合は、次を保証しない。

- 分析結果の真偽。
- 分析の完全性。
- 個別の推論や判断の妥当性、または十分な根拠づけ。
- あらゆる対象についての詳細なモデル。

Coreは `world` の完全な存在論やagentの必要十分条件を与えず、形式・意味・記述・参照・状態・遷移などの詳細も定めない。
Standardも、推論・評価の一般理論、個別moduleの構造、具体的な実行手順を定めない。
分析は利用可能な情報・区別・資源・アクセスなどの条件に応じて、部分的または暫定的でありうる。

今後、必要性が確認された場合には、個別の概念やmodule、拡張理論を追加できる。
現在の基本版はCoreとStandardを中心とし、後続moduleの完成を前提としない。

Core rev 0.4.0とStandard rev 0.2.0は、正式な現行基本版として `status: frozen`（現行として固定）とする。
両文書の理論内容とrevisionは維持している。
Core Support rev 0.3.2とStandard Support rev 0.1.2は、非CANONの補助文書として `status: draft`（変更可能）を維持する。
現行版としての固定は、上記の完成範囲や限界を変更するものではない。
